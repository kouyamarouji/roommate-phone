ROOMMATE PHONE 公式サイト 初稿
================================

【GitHubへのアップロード方法】

1. このZIPファイルをWindows上で展開します。
2. GitHubの「kouyamarouji/roommate-phone」リポジトリを開きます。
3. 「Add file」→「Upload files」を押します。
4. 展開したフォルダーの中にある次の4ファイルとassetsフォルダーをアップロードします。

   index.html
   style.css
   script.js
   favicon.svg
   assetsフォルダー

5. 画面下部の「Commit changes」を押します。
6. 数分待ってから、次のURLを開きます。

   https://kouyamarouji.github.io/roommate-phone/

【注意】

- roommate-phone-siteフォルダー自体ではなく、中にある4ファイルとassetsフォルダーをアップロードしてください。
- index.htmlがリポジトリの一番上に見える状態が正解です。
- キャラクター画像は正式素材が完成したあとで差し替える想定です。
- 発売日、価格、対応環境などは現在「未定」「予定」としています。
